# Medium Landing Page

A simplified Medium-inspired landing page built with HTML and CSS.

## 🌐 Live Demo

https://kalebosas2-dev.github.io/medium-landing-page/

## ✨ Features

* Responsive navigation bar
* Hero section
* Feature cards
* Call-to-action section
* Responsive mobile design
* Hover effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Media Queries

## 📂 Project Structure

```text
medium-landing-page/
├── index.html
├── style.css
└── README.md
```

## 🎯 Project Purpose

This project was created as a frontend development capstone project to practice semantic HTML, CSS styling, Flexbox, CSS Grid, and responsive web design.
